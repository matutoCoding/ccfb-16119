# 光导管采光设计与照度仿真系统 · Tubelight Studio

在浏览器中运行的导光管采光设计与照度仿真工具。**TypeScript + 原生 WebGL2（着色器手写）+ IndexedDB**，无重型 3D 框架、无后端。

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5188
# 或
npm run build && npm run preview   # 生产构建 + http://127.0.0.1:4173
```

精度校核（Node 命令行，积分球解析值核对）：

```bash
npm run check:physics
```

类型检查：`npm run typecheck`。

内置三套测试数据：**带货架的老厂房（48×24×8m，196 个探针）**、**地下车库（48×32m）**、**白墙精度校核间**。

## 物理与渲染要点

- **天空**：NOAA 近似太阳位置 + CIE 标准全阴天（`L/Lz=(1+2cosZ)/3`）与 CIE 晴天 Kittler 亮度分布；天顶亮度按数值积分归一到室外水平面照度。
- **光管传输**：`E罩口 × 集光面积 × 采光罩τ × 管段效率(厂家表，对数域插值) × 弯头系数^n × 漫射器τ × 维护系数`。
- **几何/BVH**：空间 → 三角面 + 材质；中点划分 BVH；节点/三角形/材质打包成 `RGBA32F` 数据纹理供着色器遍历。
- **动态漫反射 GI**：室内按网格布光照探针；每探针一张 16² 八面体纹理，分别存**辐照度**与**深度一阶/二阶矩**；探针 atlas 双缓冲递推累积，每帧只刷新若干探针，挪动货架/改反射率后重置并在数秒内可见收敛。
- **防漏光**：工作面采样邻近 8 探针的三线性权重，用深度矩做 **Chebyshev 上界可见性** `P ≤ σ²/(σ²+(d−m₁)²)`，剔除墙/货架后的探针。
- **CPU 精算**：同一套 BVH 的路径积分器，NEE 直接光（每路径随机一灯 ×灯数）+ 余弦采样多级漫反射 + 俄罗斯轮盘补足无限弹射；用于出具统计指标，确定性种子可复现。
- **统计**：`Eavg / Emin / U0=Emin/Eavg / Emin/Emax / 达标面积比`，marching-squares 等照度线，伪彩色带；货架占地自动掩膜，不污染通行区均匀度。
- **全年**：求一次全阴天采光系数 DC，8760h 用确定性典型年逐时室外照度 ×DC，统计达标时长并按光感连续调光估算照明电耗、电费与减碳。

## 验收对照（实测）

- **解析精度 < 5%**：设置页「运行积分球精度核对」，三档白墙工况（ρ=0.8/0.85/0.9）面积加权平均照度对 `E=Φ/[2(WD+WH+DH)(1−ρ)]` 的误差约 **0.1%~1.1%**；`npm run check:physics` 高密度复跑约 **0.4%**。
- **无漏光**：设置页「漏光自检」，整面到顶隔墙后的暗区/亮区 **≈0.000%**（阈值 2%）；GPU 端 Chebyshev + BVH 硬遮挡双重保证；对比/分析页对“无光源视线却出现孤立亮斑”的点列为漏光疑点（实测 0 处）。
- **200 探针性能**：老厂房 **196 个探针**，每帧增量刷新 6 个，分析页 HUD 实测 **60 FPS**（含 BVH 光线求交）。

> 说明：积分球公式严格预测的是**全内表面面积加权平均照度**；下射配光下地面/工作面值会因配光与货架遮挡而不同，系统同时列出工作面参考值。出具设计指标以 CPU 路径积分的工作面网格为准。
